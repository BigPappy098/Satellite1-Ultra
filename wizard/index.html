Satellite1 Ultra — Calibration Wizard

Turn what you measured on the printed test pieces into a corrected set of build files. Nothing to install.

Do this before you print the big parts. Print the eight pieces in PRINT_THESE_FILES/1_CALIBRATION_FIRST first, measure them as the Build Book describes, then fill this in.

1 · Printer scale

Measure the calibration piece, not the CAD. Use the same settings you will use for the enclosure.

Inside caliper jaws, taken at three different heights. Nominal is 110.60 mm.
Outside jaws, at four corners, on a clean edge. Nominal is 3.00 mm.

2 · Screws and inserts

The screw and the insert are the gauges. Do not measure these holes with caliper tips.

By hand, with no force.
No crack in the boss, no spinning.

3 · Component fit

Use your actual purchased speaker and radiators. Positive numbers make the opening bigger.

Leave at 0 if the ND91-4 dropped in by hand and sat flat.
Leave at 0 if the SB12PACR-00 dropped in by hand and sat flat.
Average of four quadrants. This sets the clamp hard stop.
Average of four quadrants, on one radiator.

4 · Gasket and cable seal

Measure your actual EPDM stock, lightly, without squashing it.
Tighten until both hard stops touch, then measure the remaining gap.
Leave at 0 if the seal and both real conductors fitted with moderate finger force.

What to do with it

    
    
      
  1. Rebuild in your browser. Open the repository's Actions tab, choose
        Calibrated build, click Run workflow, paste the file contents into the box,
        and run it. When it finishes, download the calibrated-release artifact. That zip is
        your corrected build package.
    2. 
      
  2. Or rebuild on your own machine. Save the file to
        config/physical_calibration.yaml in a clone of the repository and run
        make calibrated-release.
    3. 
    

    

      Either way: reprint every calibration piece affected by a correction you entered and re-check it.
      Only print the full enclosure once all eight checks pass on corrected pieces.
