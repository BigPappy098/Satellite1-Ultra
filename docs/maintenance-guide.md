# Maintenance guide

`VERIFIED_DIGITALLY` for access paths.

| Task | Parts to remove | Tool | New gasket required |
|---|---|---|---|
| replace the active driver | anti_slip_ring, bottom_service_plate, outer_shell, active_driver_clamp_ring | 2.0 mm hex key | yes |
| replace a passive radiator or retune its added mass | anti_slip_ring, bottom_service_plate, outer_shell, passive_radiator_clamp_ring | 2.0 mm hex key | yes |
| replace the boards | official upper stack, electronics_shroud | 2.0 mm hex key | no |
| change the ballast mass | anti_slip_ring, bottom_service_plate | 2.0 mm hex key | no |
| replace any gasket | anti_slip_ring, bottom_service_plate, outer_shell, clamp ring or pressure divider | 2.0 mm hex key | yes |

## Routine

- Vacuum the shell slots with a soft brush. Do not use solvents on ASA.
- Check the four shell screws annually; the shell is the only part that carries handling load.
- If bass output changes audibly, suspect a seal before suspecting a component: open, inspect and replace the divider gasket first.
