# Assembly guide

`VERIFIED_DIGITALLY` for the order and for tool access. Physical fit is `REQUIRES_PHYSICAL_VALIDATION` until a set of parts has been built.

The order below is the topological order of the validated dependency graph in `reports/validation/assembly.json`; it is acyclic and has no trapped parts.

1. **install all heat-set inserts** — insert along `per-feature, see fastener schedule`, tool: temperature-controlled M3 insert tip
2. **load the steel ballast, close the cartridge lid** — insert along `+Z`, tool: 2.0 mm hex key
3. **fit the active-driver gasket and driver, install the clamp ring** — insert along `-Y`, tool: 2.0 mm hex key
4. **fit both radiator gaskets and radiators, install both clamp rings** — insert along `+/-X`, tool: 2.0 mm hex key
5. **route the speaker pair through the divider and fit the TPU gland** — insert along `+Z`, tool: hand
6. **fit the divider gasket and bolt the pressure divider to the cabinet** — insert along `+Z`, tool: 2.0 mm hex key
7. **bolt the base skirt up into the acoustic floor** — insert along `+Z`, tool: 2.0 mm hex key
8. **lower the outer shell over the cabinet** — insert along `-Z`, tool: hand
9. **seat the ballast cartridge and close the bottom service plate** — insert along `+Z`, tool: 2.0 mm hex key
10. **connect the boards and bolt the electronics shroud to the divider** — insert along `+Z`, tool: 2.0 mm hex key
11. **invert and bolt the outer shell to the bottom service plate** — insert along `+Z`, tool: 2.0 mm hex key
12. **seat the official mid-plate and upper stack on the divider bosses** — insert along `+Z`, tool: 2.0 mm hex key
13. **stretch the TPU anti-slip ring onto the base** — insert along `+Z`, tool: hand

## Before you start

- All eight fit coupons have passed and their corrections are entered.
- All heat-set inserts are installed and square.
- Every gasket is cut, clean and dry. A gasket is single-use once compressed; keep a spare set.

## Torque

Every M3 joint is 0.45-0.55 Nm. All gasketed joints are hard-stopped by geometry, so torque sets clamp load, not compression. Tighten opposing pairs in two passes.
